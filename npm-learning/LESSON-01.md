# Lesson 1: Understanding npm Packages

## Package
dayjs

## Purpose
A JavaScript library for working with dates and times.

## What I learned
- npm downloads and manages packages.
- package.json declares dependencies.
- package-lock.json records resolved dependency versions.
- node_modules makes installed packages available to the project.
- import allows my code to use exported package functionality.

## Experiment
Installed dayjs and used it to format the current date.
